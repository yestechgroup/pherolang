# Highlight corpus

Checked inputs for the compiler-backed highlighter. Every case is highlighted
in strict mode by `crates/phero-highlight/tests/corpus.rs`; the generated
summaries under `tests/highlight/summary/` pin the semantic-class counts and
the representative exact-span goldens under `tests/highlight/json/corpus.*`
pin the full span stream.

Layout: one directory per surface (`valid`, `truncated`, `parse-error`, plus
the surface-specific cases) and `shared/` for cross-cutting bytes (Unicode,
CRLF, escapes, comments). The corpus is deliberately **outside**
`tests/conformance/`: `pherolang check tests/conformance/` must never treat a
fragment as a standalone model.

Regenerate the summaries and exact-span goldens after a deliberate engine,
parser, or vocabulary change, then read the diff:

```sh
PHERO_UPDATE_FIXTURES=1 cargo test -p phero-highlight --test corpus
```

The docs-fence summary (`tests/highlight/summary/docs-fences.json`) covers
every Phero Lang fence in `docs/**/*.md`. It is regenerated by the same
command; a new fence is a corpus change even when no source file here moves.
